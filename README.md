# AI-Powered Cybersecurity

An AI-powered cybersecurity project combining **email spoofing detection** and **facial recognition** to explore intelligent approaches to email security and identity verification.

## Overview

This project brings together two cybersecurity applications:

- **Email Spoofing Detection:** A system designed to identify potentially spoofed emails and help detect email-based impersonation.
- **Face Recognition:** A facial recognition application that integrates AI-based face recognition with a backend for student management and authentication.

## Features

### 1. Email Spoofing Detection
- Email spoofing detection interface.
- Tools for analyzing potentially suspicious emails.
- A dedicated module for email security.

### 2. Face Recognition
- AI-based facial recognition.
- Backend authentication and student management.
- Organized backend architecture with routers, models, schemas, and services.
